## Project Description

MOTION is a fictional fitness and wellness platform designed for people who want to build healthier routines, improve their fitness, and stay active. The landing page introduces the platform's workout options, wellness guidance, and progress-tracking features.

## Objective

To design an attractive, user-friendly, and responsive fitness landing page using Figma's Auto Layout, reusable components, and shared design styles.

## Target Audience

- Fitness beginners
- College students and young adults
- People who want to build healthier daily habits
- Individuals looking for simple workout routines
- People who want to track their fitness progress

## Main Sections

- Header with MOTION logo, navigation links, and join call-to-action button
- Hero section with headline, description, fitness illustration, and primary button
- Introductory statistics section
- Three feature cards: Workouts for You, Everyday Wellness, and See Your Progress
- Call-to-action section
- Footer with brand information and useful links
- Desktop and mobile layouts

## Project Deliverables

- Desktop landing page
- Mobile landing page
- Responsive UI design
- At least three reusable components
- Auto Layout
- Shared color and typography styles
- Design documentation
